# Lab 9 — Clima

Đọc hướng dẫn chi tiết trong `docs/HUONG_DAN_9_LAB.md` ở thư mục gốc bộ bài tập.
Chỉnh sửa mã trong app này sau khi đã chạy setup.

```powershell
flutter pub get
flutter analyze
flutter run -d chrome
```

Lab này có test: chạy `flutter test`.
Clima cần key: dùng `flutter run -d chrome --dart-define-from-file=secrets.json` thay lệnh run thông thường. Xem README gốc để tạo file key.

Mã mẫu chưa được chạy Flutter trong môi trường tạo file; cần xác nhận trên máy bạn.
